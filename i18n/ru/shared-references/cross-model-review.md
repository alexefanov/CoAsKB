# Кросс-модельная рецензия

> Общий референс для /review и всех скиллов, вызывающих кросс-модельную рецензию:
> /ideate, /novelty, /exp-eval, /paper-plan, /paper-draft, /rebuttal, /refine.
> Использует внешнюю LLM через MCP-сервер Review LLM, настроенный в .env.

---

## Настройка

Review LLM должен быть настроен в `.env`:

```env
LLM_API_KEY=sk-...        # API-ключ провайдера
LLM_BASE_URL=https://...  # URL, совместимый с OpenAI
LLM_MODEL=gpt-4o          # или deepseek-chat, qwen-max и т.д.
```

Без этой настройки скиллы пропускают шаг кросс-модельной рецензии и работают только с одной моделью.

## Протокол

### Шаг 1: Подготовка

Перед вызовом Review LLM собери:

- **Артефакт**: полный текст для рецензии (статья, план, идея, набор результатов)
- **Контекст**: что это, для чего, какие критерии оценки
- **Специфические инструкции**: на что обратить особое внимание

### Шаг 2: Запрос к Review LLM

```json
{
  "artifact": "<полный текст артефакта>",
  "context": "<контекст и назначение>",
  "criteria": ["novelty", "correctness", "completeness", "clarity"],
  "specific_instructions": "<что проверить особенно>"
}
```

### Шаг 3: Сравнение

Сравни рецензию от Review LLM с собственной рецензией:

| Аспект | Моя рецензия | Review LLM | Консенсус |
|--------|-------------|------------|-----------|
| novelty | 7/10 | 6/10 | 6.5/10 |
| correctness | 8/10 | 7/10 | 7.5/10 |

### Шаг 4: Сводный отчёт

- **Совпадающие замечания**: выделить как критические
- **Расхождения**: отметить, запросить уточнение у пользователя
- **Итоговая оценка**: среднее или консенсус

## Когда Review LLM недоступен

Если Review LLM не настроен (нет LLM_API_KEY / LLM_BASE_URL):

- Пропусти шаг 2-3
- Действуй только с собственной рецензией
- Отметь в отчёте: «Кросс-модельная рецензия не выполнялась — Review LLM не настроен»

## Интеграция со скиллами

### /review
- Основной потребитель. Выполняет полный кросс-модельный обзор.

### /ideate (Фаза 3: Фильтрация)
- Передаёт каждую сгенерированную идею в Review LLM для независимой оценки новизны.

### /novelty
- Передаёт идею в Review LLM как часть многоисточниковой проверки новизны.

### /exp-eval
- Передаёт результаты эксперимента + гипотезу для независимой оценки корректности выводов.

### /paper-plan
- Передаёт план статьи для проверки логики и полноты.

### /paper-draft
- Передаёт черновик раздела для проверки ясности и аргументации.

### /rebuttal
- Передаёт комментарий рецензента + проект ответа для оценки убедительности.

### /refine
- На каждом раунде передаёт улучшенный артефакт для переоценки.

## Обработка ошибок

- **Review LLM не отвечает**: пропустить шаг, продолжить с одной моделью
- **Review LLM даёт нерелевантный ответ**: отметить расхождение, запросить у пользователя
- **Превышение лимита контекста**: сократить артефакт (передать только ключевые разделы)
