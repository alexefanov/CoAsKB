## Проблемы соответствия

### 1. Полное соответствие (удалить дубликат)
| AutoSci | Русский | Действие |
|---------|---------|----------|
| `introduces_concept` | `вводит_термин` | Оставить `вводит_термин`, удалить `introduces_concept` |
| `uses_concept` | `использует_термин` | Оставить `использует_термин`, удалить `uses_concept` |
| `derived_from` | `происходит_из` | Оставить `происходит_из`, удалить `derived_from` |

### 2. Частичное соответствие (доработать)
| AutoSci | Русский | Проблема | Решение |
|---------|---------|----------|---------|
| `cites` | `цитирует` | Разные атрибуты | Унифицировать: оставить `источник`/`дата`/`пункт`/`контекст` |
| `builds_on` | `дополняет` | Разные from/to | Уточнить: `builds_on` = papers→papers, `дополняет` = papers→concepts |
| `extends_concept` | `дополняет` | Разные workflow | Оставить `дополняет` для concepts, добавить `расширяет` для papers→concepts |
| `critiques_concept` | `противоречит` | Разные workflow | Оставить `противоречит` для check, добавить `критикует` для ideas→concepts |
| `challenges` | `противоречит` | Разные workflow | Оставить `противоречит` для check, добавить `оспаривает` для papers→papers |
| `supports` | `подтверждает` | Разные from/to | Оставить `подтверждает` для [methods, experiments]→concepts |
| `contradicts` | `противоречит` | Разные from/to | Оставить `противоречит` для *→* |
| `tested_by` | `проверяет_задачу` | Обратное направление | Оставить `проверяет_задачу` (experiments→ideas) |
| `invalidates` | `противоречит` | Разные workflow | Оставить `противоречит` для check, добавить `опровергает` для experiments→ideas |
