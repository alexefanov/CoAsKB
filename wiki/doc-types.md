# Типы нормативных документов

Источник: `runtime/schema/doc-types.yaml`

Агент дополняет этот список при ingest нового типа документа, которого нет в YAML.

| Ключ | Наименование | Аббревиатуры | Статус |
|------|-------------|--------------|--------|
| ГОСТ | Государственный стандарт (межгосударственный) | ГОСТ | Действующий |
| ГОСТ Р | Государственный стандарт Российской Федерации | ГОСТ Р | Действующий |
| ГОСТ Р ИСО | Государственный стандарт РФ, гармонизированный с ИСО | ГОСТ Р ИСО | Действующий |
| СП | Свод правил | СП | Действующий |
| СНиП | Строительные нормы и правила | СНиП | Заменён СП |
| ФЗ | Федеральный закон | ФЗ | Действующий |
| Кодекс | Кодекс Российской Федерации | Кодекс | Действующий |
| Постановление | Постановление (Пленума ВС/ВАС, Правительства РФ) | Постановление, ПП | Действующий |
| Приказ | Приказ министерства/ведомства | Приказ | Действующий |
| ОДМ | Общероссийский методический документ (дорожно-строительный) | ОДМ | Действующий |
| МДС | Методические документы в строительстве | МДС | Действующий |
| РД | Руководящий документ | РД | Действующий |
| СТО | Стандарт организации (объединения) | СТО, СТО НОСТРОЙ, СТО Газпром | Действующий |
| ВСН | Ведомственные строительные нормы | ВСН | Действующий |
| МРР | Межрегиональные расценки | МРР | Действующий |
| Пособие | Пособие по проектированию/строительству | Пособие | Справочный |
| Рекомендации | Рекомендации (ведомственные, отраслевые) | Рекомендации, Р | Справочный |
| другое | Документ, не попадающий в перечисленные категории | — | Неизвестный |
